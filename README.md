## Local development

The application requires the following environment variables:

- `DB_URL`
- `DB_USERNAME`
- `DB_PASSWORD`

Example values:

```text
DB_URL=jdbc:postgresql://localhost:5432/tennis_scoreboard
DB_USERNAME=tennis_app
DB_PASSWORD=<your-actual-password>
